# Original MATLAB code (2023)

Code of the course project *Problema de los n-cuerpos* by Ginés Haro Pérez and
Jesús García Izquierdo, kept unchanged (including its Spanish comments) for reference.

| File | Content |
|---|---|
| `Gravedad_clasica.m` | Two-body version of the velocity Verlet integrator |
| `Gravedad_clasica_2.m` | General N-body version: Verlet, momentum, energies, angular momentum |
| `Juego_de_azar.m` | Random initial conditions ("game of chance") illustrating chaos |

The Python package in `nbody/` supersedes this code; see [docs/FROM_MATLAB.md](../docs/FROM_MATLAB.md)
for the correspondence and the fixes.
